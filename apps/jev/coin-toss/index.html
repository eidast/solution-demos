Three ways to answer

All three see the same state before the coin is flipped. Choice selects a named side; Noul gives P(heads); Score places the answer between tails (0) and heads (1). Score is a diagnostic use of an ordered scale for a two-category event.

Score

0 / 0Heads 0 · tails 0 · undecided 0Brier —Position 0=tails, 1=heads

Accuracy is correct predictions out of non-undecided predictions. Brier scores the heads forecast against the coin result; lower is better, and 0.25 is the expected score for a constant 0.5 forecast. Score uses its heads-rung probability for this diagnostic. No method can see the independent future result.
