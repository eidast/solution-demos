# Design

Use a 45-second excerpt from source second zero of Shibuya Crossing (640×480 source, CC BY 2.0). Preserve 4:3 in a 960×720, 12 FPS playback derivative (540 frames); upscaling adds no source detail. Local source preparation downloads fixed hash-checked footage and model weights. An original-only preparation option makes source.mp4 and its hash manifest available without inference.

The page starts in Original mode, independent of analysis readiness. Analyze video sends a bodyless same-origin POST with a custom action header. The handler requires a loopback peer and loopback origin matching Host; it rejects cross-site requests, request bodies, non-loopback origins, and unexpected methods. The controller checks a fixed venv interpreter, script, cached weights, and prepared source; spawns only `prepare.py --analyze` without a shell; forwards only necessary non-secret environment values; allows one job; and terminates at five minutes. No arbitrary inputs or paid keys enter the worker. Status reports validated integer progress, stage, and controlled errors. Worker stderr is never forwarded to the browser.

Python emits JSON progress, checks the fixed source manifest and model hashes, performs actual YOLOX inference and Supervision annotations, draws a two-color translucent HUD with current-frame counts and timestamp, then publishes complete annotated video and schema-v2 analysis only on success. Original media is not modified by inference. Output replacement remains fixed local files, retained until replaced or manually removed; job status is in memory only. Reloading a page can reconnect to a running job. Re-analysis disables source switching and discards stale browser analysis; original playback remains available if analysis fails.

Use a single video player with an accessible Show detections & HUD toggle. Switching sources preserves the frame and play/pause intent. Counts and HUD use the same accepted detections, never cumulative sums. The original is silent/transcoded for browser compatibility but contains no added boxes or HUD. Existing static allowlists and media byte-range handling remain in place.
